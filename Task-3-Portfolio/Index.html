About Me

Hi, I’m Payal Singh, a passionate web developer and creative designer. I love building interactive websites and applications, and I also enjoy designing visually appealing projects in Canva.

My coding journey includes projects like Kushaa Interiors (an interior design website), an Expense Tracker, a Music Player, and a Python Calculator. Alongside development, I’ve designed professional brand logos for a Saree Shop, a Coffee Shop, and Nitro Gym, plus creative works like coloring books.

I’m skilled in Python, C++, C, and Java basics, and I also work with modern web technologies like HTML, CSS, JavaScript, React, Bootstrap, and Tailwind. My goal is to combine technical expertise with design creativity to deliver projects that are both functional and beautiful.
